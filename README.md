# suzumushi-front

The static landing page for [Suzumushi](https://github.com/nuggocto/suzumushi),
a calm, fully local terminal audio player for Linux.

## Development

```sh
pnpm install
pnpm dev
```

Run the complete local gate with:

```sh
pnpm verify
```

The site is built as static files and deployed to Cloudflare Pages from the
`shrek` branch. Production is available at [suzumushi.org](https://suzumushi.org).
